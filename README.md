# P.L.I.S.

**Pocket Lab for Interactive Schematics** — **Портативная Лаборатория Инженерных Схем**

Редактор электрических схем для телефона. Рисуйте схемы пальцем: детали по ГОСТ и IEC, провода, узлы,
выделение рамкой, отмена, сохранение в файл и в картинку. Работает полностью **без интернета**:
у приложения даже нет разрешения на доступ к сети.

## Возможности

- Более 60 условных графических обозначений: резисторы, конденсаторы (в том числе полярные и подстроечные),
  катушки, трансформатор, диоды всех видов, тиристоры, транзисторы, логические элементы, микросхемы, модули.
- Микросхемы серий К155, К561, К174 с номерами выводов и **универсальная микросхема**, у которой число выводов
  и их имена задаёт сам пользователь.
- Провода под прямым углом, узлы (автоматические и ручные), выделение рамкой, поворот и перенос группы.
- Сохранение, сохранение схемы в файл (`.json`) и в картинку (`.png`), открытие сохранённых схем.
- Тёмная тема, масштаб и сдвиг двумя пальцами.

## Установка

Готовый `.apk` лежит в разделе **Releases**. Скачайте его, разрешите установку из этого источника и установите.
Требуется Android 7.0 или новее.

## Сборка

Нужны JDK 17 или новее, Android SDK (platforms и build-tools) и утилита `zip`. Gradle и сторонние библиотеки **не нужны**.

```sh
export ANDROID_HOME=/путь/к/android-sdk
./build.sh            # или: make apk
```

Результат: `dist/plis-<версия>.apk`. Без ключа релиза приложение подписывается тестовым ключом
(в имени файла будет `-debug`).

### Автоматическая сборка на GitHub

Файл `.github/workflows/build.yml` собирает `.apk` при каждом изменении кода. Чтобы выпустить версию:

1. Поменяйте номер в файле `VERSION` (например, `0.1.0`).
2. Поставьте метку: `git tag v0.1.0 && git push --tags`.
3. Через несколько минут `.apk` появится в **Releases**.

### Подпись релизов

Android обновляет приложение только если новый `.apk` подписан **тем же ключом**, поэтому ключ создаётся один раз
и хранится в надёжном месте. **В репозиторий его класть нельзя.**

```sh
keytool -genkeypair -keystore plis.jks -alias plis -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 plis.jks      # результат кладём в секрет PLIS_KEYSTORE_B64
```

В настройках репозитория (Settings → Secrets and variables → Actions) добавьте секреты:
`PLIS_KEYSTORE_B64`, `PLIS_KEY_ALIAS` (`plis`), `PLIS_KS_PASS`, `PLIS_KEY_PASS`.

## Устройство проекта

```
web/index.html                        весь редактор (HTML + JavaScript)
android/src/org/plis/editor/          оболочка на Java: окно, сохранение и открытие файлов
android/AndroidManifest.xml           идентификатор приложения: org.plis.editor
android/res/                          значок и ресурсы
build.sh, Makefile                    сборка без Gradle
.github/workflows/build.yml           автосборка и выкладка релизов
tools/                                значок и загрузка текста лицензии
VERSION                               номер версии
```

Оболочка использует только то, что есть в самом Android, поэтому все файлы проекта распространяются
под одной лицензией.

## Откуда взяты обозначения и данные

- Все условные графические обозначения **нарисованы с нуля** по стандартам ГОСТ и IEC. Файлы, рисунки и
  библиотеки сторонних программ в проект не входят.
- Назначение выводов микросхем взято из общедоступных справочников и документации. **Перед пайкой сверяйте
  номера выводов с даташитом**, ошибки возможны.
- Проект не связан с sPlan и его правообладателями.

## English (short)

**P.L.I.S. — Pocket Lab for Interactive Schematics** is an offline electronic schematic editor for Android phones.
It ships ~60 GOST/IEC symbols (drawn from scratch), orthogonal wires, nodes, box selection, undo, and export to
JSON/PNG. No network permission, no third‑party libraries, no Gradle: `./build.sh` builds a signed APK with the
